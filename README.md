# sanidhya.tech

Personal site — writing first, everything else behind it. Hugo, [mana](https://github.com/Livour/hugo-mana-theme) theme, deployed on Vercel.

The site lives in `blog/`, which is the Vercel project root.

```sh
git clone --recurse-submodules <repo>
cd blog
hugo server
```

Posts go in `blog/content/posts/`. `about.md` and `work.md` are the standing pages.

{{- /* Robots meta tag for SEO */ -}} {{- if eq .Kind "404" -}} {{- else if and (eq .Kind "term") (lt (len .Pages) 3) -}} {{- /* Thin taxonomy pages: one or two posts isn't a useful landing page, and they dilute what Google judges the site on. Follow, don't index, until the tag earns its own page. */ -}} {{- else -}} {{- $robots := slice -}} {{- if .Params.noindex -}} {{- $robots = $robots | append "noindex" -}} {{- end -}} {{- if .Params.nofollow -}} {{- $robots = $robots | append "nofollow" -}} {{- end -}} {{- if .Params.noarchive -}} {{- $robots = $robots | append "noarchive" -}} {{- end -}} {{- if .Params.nosnippet -}} {{- $robots = $robots | append "nosnippet" -}} {{- end -}} {{- if eq (len $robots) 0 -}} {{- $robots = $robots | append "index" "follow" -}} {{- end -}} {{- end -}}

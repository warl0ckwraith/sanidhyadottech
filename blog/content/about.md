I got into security by messing around with tools I barely understood until something
clicked. That turned into offensive work — penetration testing, red team engagements,
CTF development — and offensive work turned into an interest in the other half of the
problem: how you actually design and build systems that hold up.

These days most of my time goes into security tooling and research. Knowing how things
break is the useful half of knowing how to build them so they don't.

Currently finishing a B.Tech in Computer Science (Cyber Security & Digital Forensics) at
VIT Bhopal, where I run the OWASP student chapter, and taking on independent security
work alongside it.

## What I work on

- **Security tooling** — scanning, exploitation and automation frameworks, mostly Python and Docker
- **Vulnerability research** — most recently [CVE-2025-65875](/posts/security-research/cve-2025-65875-fpdf-rce-vulnerability/), an RCE in FPDF
- **Offensive security** — web, mobile and network penetration testing; red/purple team exercises
- **CTF design** — 50+ challenges built for conferences and competitions
